# Звук и видео

## `DSFX` — опознано

`Enviroment.sfx` (так файл назван в обеих играх), `game.sfx`, `menu.sfx`,
`Voice*.sfx`.

Заголовок `menu.sfx` первой игры (6 390 848 байт):

```
char magic[4] = "DSFX"
u32  53            // правдоподобно число клипов
u32  6389392       // близко к размеру файла минус небольшой заголовок
u32  592
```

Дальше бинарные кадры без читаемых имён. Похоже на сжатые клипы с таблицей
в заголовке. Формат сжатия (ADPCM или иное) не определён: сигнатуры `RIFF`
внутри банка нет в первых строковых пробах.

Голос разложен по банкам, не по отдельным wav:

- первая игра: `Voice0.sfx` … `Voice6.sfx`
- вторая: `Voice00.sfx` … `Voice10.sfx` (больше языков или больше реплик)

Миссия второй игры в `.gsl` ссылается на эти банки списком `Voice Files`
(`voice00.sfx` …). Какая реплика каким смещением лежит внутри банка, не
известно.

## `GSND` — каталог

`sounds.dat`, около 110 КБ в обеих играх.

```
char magic[4] = "GSND"
u32  1420          // 1489 во второй игре
u32  45440
u32  42496
u32  299636        // одинаковый в обеих играх
```

Имён в открытом виде нет (в отличие от контейнера `DATA`). Четвёртое поле
совпадает у двух разных файлов — возможно, ссылка на общий банк, а не размер
этого файла. Назначение «индекс звуков» выведено из магика и размера, не из
разобранной таблицы.

## `Menu.wav` — разобрано

Обычный PCM WAV, одинаковый в обеих играх:

- `RIFF` / `WAVE`, `fmt ` 16 байт, формат 1 (PCM)
- 2 канала, 44100 Гц, 16 бит, байтрейт 176400
- данные с четвертого поля заголовка, около 44 МБ

Это единственный несжатый звук в `Data/`.

## Видео — каталог

Первая игра, `Data/Movies/`: `Logo.wmv`, `Intro.wmv`, `Storm.wmv`,
`Intermediate.wmv`, `Outro.wmv`. Магик ASF (`30 26 b2 75 …`).

Вторая игра: `intro.avi`, `outro.avi`, `op1.avi` … `op7.avi`. Обычный
`RIFF` / `AVI`. Рядом с исполняемым файлом есть `Video.dll`.

В `Configs.cfg` среди ключей видео есть имена `intro`, `storm`, `intermediate`,
`outro`, `wmv`. Ролики перечислены в настройках, не вшиты в миссию как
отдельный формат субтитров.
