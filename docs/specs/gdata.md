# `gdata.dat` — база юнитов

Файл — контейнер `DATA`. Внутри одной из записей лежит текст
`[STORM CRAFTS DATA FILE V1.1]`. Парсер корпуса самолёта —
`parse_craft_hull` в `tools/legacy_export.py`: `Craft("Human_BF1")`, `Root`,
`FileName`, дерево `Part` с `Position`. `Position` в этой базе — не размещение
мешей (по виду это точки попадания или крепления). Экспортёр берёт его только
если узел в `objects.dat` не нашёлся. Рабочие координаты частей — из
`objects.dat`, оси — в [containers.md](containers.md). `ViewDelta` и
`BackViewDelta` лежат здесь же и тоже в системе D3D.

Кривые полёта записаны текстом, уже переносятся в `assets/data/crafts/*.json`:

```
ThrustCFromAlt (0 2.2)(100 1)(1200 .85)(1500 .25)
```

## Какие сущности объявлены

Подсчёт вызовов `Имя(` по всему файлу (вместе с вложенными, не только техника).

Первая игра: `Craft` 28, `Vehicle` 40, `Turret` 115, `Gun` 17, `Plasma` 16,
`Rocket` 6, `Missile` 9, `Radar` 16, `Hangar` 11, `SeaCarrier` 9,
`AirCarrier` 4, `Plane` 6, `Foot` 6, `Road` 4, `Debris` 30, `Expl` 161,
`ExplOnStart` 164, `ExplOnEnd` 49, `ExplOnTime` 5, `Static` 261, `Layout` 340,
`Subobj` 34, `SFG` 11, `Dust` 2, `Part` 1856, `Root` 370.

Во второй игре тех же вызовов больше, и появляются новые:

| Вызов | Сколько | Смысл по имени и соседству |
| --- | --- | --- |
| `DetachedPart` | 1822 | Отрываемая деталь. В первой игре такого ключа нет |
| `Animation` | 172 | Клип анимации, отдельного файла анимаций нет |
| `AnimationPackage` | 29 | Набор клипов на юнит |
| `HTGR` | 3 | Тип группы, рядом в командах миссии есть `StdHTGR` |
| `Sfg` | 12 | То же семейство, что `SFG` первой игры (наземная огневая группа) |

Отдельного формата скелетной анимации на диске нет. Анимация — поля внутри
этой текстовой базы, и только во второй игре.

## Что это говорит о составе игры

База описывает не только самолёты. В одном файле живут пушки, ракеты, плазма,
радары, ангары, авианосцы и морские носители, пехота (`Foot`), дороги, турели,
статичные здания, обломки и несколько видов взрывов (старт / конец / по
таймеру). Вторая игра добавляет явный отрыв детали и анимационные пакеты.

Поля конкретных `Gun` / `Missile` / `Animation` (скорострельность, скорость
снаряда, имена клипов) ещё не выписаны. Разобран из этой базы только корпус
самолёта и кривые тяги.
