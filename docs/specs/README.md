# Спецификации оригинала

Поверхностный разбор установленных игр в `legacy/` (не коммитится):

- «Шторм» / Echelon, Steam 311080 — `legacy/Echelon`
- «Шторм: Солдаты Неба» / Echelon: Wind Warriors, Steam 311100 —
  `legacy/Echelon Wind Warriors`

Движок MADia «Storm», DirectX 7, исходников нет. Мультиплеер (сокеты, GameSpy,
`dedicated.exe`, бан-листы, лобби) сознательно не разбирался: файлы только
названы в [каталоге](inventory.md).

Спецификации описывают, **что лежит в файлах оригинала**, как мы это экспортируем
и какие вопросы ещё открыты. Сборка, соглашения движка и предостережения
«так делать нельзя» остаются в `AGENTS.MD`.
Решение «перенести данные» или «написать заново» здесь не принимается — для
этого в [механиках](mechanics.md) у каждой системы стоит пометка, данные это
или поведение.

## Как читать уверенность

- **разобрано** — формат читается нашим кодом или сверен побайтно на нескольких
  файлах.
- **опознано** — магик, размеры и роль ясны, поля внутри не разобраны.
- **каталог** — файл есть, назначение выведено из имени, соседей и строк.
  Раскладка неизвестна.

Числа ниже сняты с этих двух установок. Другой патч может отличаться.
